Пошук пристроїв у мережі

Опитує підмережу Wi-Fi (STA), до якої підключений хаб — так само, як пошук по Bluetooth, тільки по локальній мережі. Знаходить будь-які активні пристрої (не тільки розетки), навіть ті, що не відповідають на ping (позначені "без ping" — типово для файрволу чи деяких IoT-прошивок); ті, що відповідають на порту 80, додатково перевіряються на Shelly/Tasmota/ESPHome — якщо розпізнано, клік одразу підставить готовий URL керування, якщо ні — тільки IP, як і раніше. Точки доступу пристрою (192.168.4.x) та інші підмережі цим способом не бачити.
Пошук безперервний: після "Почати пошук" хаб перебирає підмережу по колу, поки не знайде розетку (пропускаючи вже знайдені) — не обов'язково знаходить усе з першого разу. Триває, поки не оберете рядок, не натиснете "Завершити пошук", чи не закриєте вікно (це теж зупиняє пошук).
