# Сайт-інструкція Smart Plug Control

Статичний сайт (чистий HTML/CSS/JS, без збірки й залежностей). Публікується через GitHub Pages з цієї теки.

## Публікація (один раз)

1. Репозиторій має бути **публічним** (для безкоштовного плану).
2. GitHub → **Settings → Pages → Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **master**, folder: **/docs** → Save.
3. Через ~1 хв сайт буде доступний на `https://vmexanik.github.io/smart-plug-control/`.

Далі кожен `git push` у `master` сам перепублікує сайт.

## Локальний перегляд

```bash
cd docs
python -m http.server 8000
# відкрити http://localhost:8000
```

Не відкривайте файли подвійним кліком (`file://`): демо використовує `fetch`, а той у браузерах на `file://` обмежений.

## Структура

```
docs/
  index.html … faq.html     сторінки (кожна самодостатня, навігація додається з assets/site.js)
  assets/site.css           стилі (світла/темна тема)
  assets/site.js            меню, «Далі/Назад», кнопки «Копіювати», перемикач теми
  demo/                     інтерактивне демо веб-інтерфейсу (див. нижче)
  sync-demo.py              оновлення демо з main/web/
  .nojekyll                 вимикає обробку Jekyll
```

### Додати сторінку

1. Скопіюйте будь-яку сторінку (наприклад `faq.html`) і змініть вміст у `<main>`.
2. Додайте рядок у масив `PAGES` у `assets/site.js`: меню й «Далі/Назад» оновляться самі.

## Демо веб-інтерфейсу

`demo/` це **справжній** інтерфейс прошивки (`main/web/`) із підміненим API: `demo/mock.js` перехоплює `fetch('/api/…')` і відповідає вигаданими даними. У правому нижньому куті є симулятор входів: повзунок напруги й прапорці DC1/DC2.

Після кожної зміни `main/web/*` запускайте:

```bash
python docs/sync-demo.py
```

Скрипт скопіює `app.js`, `style.css`, `favicon.svg`, переробить `index.html` (відносні шляхи + підключення `mock.js`) і зупиниться з помилкою, якщо структура `index.html` змінилась так, що перетворення не спрацювало.

Якщо у прошивці з'явився новий ендпоінт `/api/…`, додайте його у функцію `route()` в `demo/mock.js`. Поки цього не зроблено, демо показує повідомлення «У демо цей запит не підтримується».

## Що підтримувати разом із кодом

Сторінки написані за кодом прошивки версії 2.1.x. Якщо змінюється поведінка, оновіть відповідну сторінку:

| Зміна в прошивці | Сторінка |
|---|---|
| Піни, `Kconfig.projbuild` | `hardware.html`, `maintenance.html` (таблиця параметрів) |
| Логіка входів, інверсія, затримка | `hardware.html`, `interface.html` |
| Межі/калібрування AC | `ac.html` |
| Нові драйвери, нові сімейства в пошуку | `devices.html` |
| Поля форм/вкладки UI | `interface.html` (+ `sync-demo.py` для демо) |
| Розмітка пам'яті, OTA | `maintenance.html` |
